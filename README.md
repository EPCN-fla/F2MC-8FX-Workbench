# F2MC-8FX-Workbench

## 📖 插件简介

本插件旨在替代 F2MC-8L/8FX Family SOFTUNE Workbench V3 软件，在 VSC 上实现富士通 F2MC-8FX 系列单片机完整的开发流程。

---

## 🛠️ 功能特性

- 支持导入 SOFTUNE 工作区
- 支持类似 SOFTUNE 工作区目录显示
- 支持类似 SOFTUNE 构建器配置
- 可一键编译，生成 mhx/ihx/ehx/hex 文件
- 支持多种编程器（上海泽兆烧录器、F2MC-LINK 自制编程器）烧录/擦除/校验

---

## 🏃‍♀️ 快速上手

1. 打开扩展活动栏，点击“导入工程”
2. 选择工程文件 (.wsp)
3. 插件会自动解析内容，并创建对应的 VS Code 工作区
4. 选择“打开工作区”后，在活动栏中可以查看工程结构
5. 点击编译按钮，生成烧录文件
6. 点击烧录按钮，匹配烧录器，将程序下载至目标中

---

## 🔥 烧录指南

在插件“设置”视图的“编程器配置”中选择烧录器型号：`Zeztek`（默认，上海泽兆）或 `F2MC-LINK`（自制编程器）。编程器相关配置（型号选择、编程器模式、目标电压、写安全位、复位运行）支持修改。

### 上海泽兆烧录器

**v0.2.0** 开始支持上海泽兆（Zeztek）EasyProgramer 烧录器（USB 串口，CP210x 驱动），串口协议依据原上位机逆向并真机验证。

#### 使用步骤

1. 编译工程，生成 `.mhx` 烧录文件（烧录器仅支持 S-record 格式）
2. 烧录器通过 USB 连接电脑，**目标板保持断电**（由烧录器盒子控制目标供电）
3. 点击状态栏或编辑器标题栏的“烧录”按钮
4. 串口自动检测（按 CP210x 特征匹配）；检测到多个烧录器时弹出选择
5. 等待进度完成：传输数据 → 擦除、编程、校验，成功后显示文件校验和，**盒子数码管应显示其后 4 位**（可直接对照确认）

#### 编程器配置（“设置”视图 →“编程器配置”）

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| 编程器模式 | 烧写方式（离线=参数与固件保存到烧录器，也可按盒子编程键烧写；在线=全程 PC 控制） | 离线 |
| 目标电压 | 目标芯片供电电压 | 5V |

#### 芯片支持

当前支持的芯片型号：`MB95F636H/K`、`MB95F634H/K`（与烧录器固件 MCUtype 表一致，如需扩展请补充 `src/flasher/zeztek/mcuTable.ts`）。
其中 `MB95F636H/K` 已经真机完整验证；`MB95F634H/K` 型号表数据与烧录器厂商 MCUtype 表一致，但尚未真机验证。

> 💡 **注意**
>
> - 烧录器为 CP210x USB 串口设备：Windows 10/11 联网时系统一般会自动安装驱动；
>   未自动安装或使用老系统时，手动安装一次随烧录器附带的 CP210x 驱动
>   （或从 Silicon Labs 官网下载）即可，之后无需再装。
> - 烧录过程中请勿断开烧录器或强制取消，否则烧录器可能进入异常状态需要重新上电。
> - **连续烧录时，每次烧录完成后请先给烧录器断电重新上电**（盒子固件以此分隔烧录会话，
>   原版上位机同样如此）；若点烧录时提示未响应，重新上电后点重试即可。
> - 离线模式下也可以脱离 PC：装载完成后直接按盒子上的编程键完成擦除、编程、校验。

### F2MC-LINK 自制编程器

**v0.2.1** 开始原生支持 [F2MC-8FX-Programmer](https://github.com/EPCN-fla/F2MC-8FX-Programmer) 开源自制编程器。插件内置 CMSIS-DAP v1(HID) 传输与 vendor 协议客户端（移植自其 Rust 上位机 f2mc-core），**USB 全平台免驱**（Win7 兼容），无需安装任何上位机软件。烧录流程：进入编程模式 → 整片擦除 → 分块写入 → 读回校验。

#### 使用步骤

1. 按 F2MC-8FX-Programmer 仓库说明制作硬件并烧录固件
2. 在“设置”视图“编程器配置”→“型号选择”中切换为 F2MC-LINK
3. 编译工程，生成 `.mhx`/`.hex` 等烧录文件（Intel HEX 与 S-record 自动嗅探，不受格式限制）
4. 编程器连接 USB（自动上电控制目标板，仅裸片烧录，通流 ≤50mA）
5. 点击“烧录”按钮，等待完成（36KB 全片约 30~45 s），进度与协议日志输出在“F2MC-8FX Build”通道

#### 编程器配置（“设置”视图 →“编程器配置”，选择 F2MC-LINK 后显示）

| 配置项 | 说明 | 默认值 |
| --- | --- | --- |
| 写安全位 | 烧录完成后写安全位（0xFFFC=0x01），锁片后需整片擦除解锁（烧录时自动处理） | 关闭 |
| 复位运行 | 烧录完成后复位运行（断电重新上电）；关闭则保持编程模式便于连续烧录 | 开启 |

#### 芯片支持

支持 F2MC-8FX 全部 216 款型号（内置型号库，与插件芯片选择共用 `res/896.csv`），直接使用工程所选芯片型号，无需额外配置。

> 💡 **注意**
>
> - 烧录过程中点进度通知的“取消”可秒级强制中止（ABORT 带外命令）。
> - 已加安全锁的芯片会自动整片擦除解锁后重试。
> - NVR 区（0xFFBB~0xFFBF）数据自动剔除，CR Trimming 失配自动回写。

## 🙋 协助开发

欢迎各位对本插件进行功能完善、拓展。

**提 PR 时，请选择最新版本分支而非 main 分支。**

以下是开发环境搭建流程：

> 💡 **注意**
>
> 请确保你已经安装了以下软件：
>
> - Python (>= 3.10)
> - Microsoft Visual Studio & Desktop development with C++ (>= 2017)

> 📦 **包管理器**
>
> 本工程同时支持 *yarn*（首选）与 *npm*，仓库中保留 `yarn.lock` 与 `package-lock.json` 双锁文件。
>
> **更改依赖时必须同步维护两个锁文件**：每次增删/升级依赖后，需分别执行 `yarn install` 与 `npm install`，否则可能导致两种工具解析出的依赖版本不一致。

**共同步骤**：安装 *NodeJS*（推荐使用 nvm 工具，版本选择 v20.20.2）

接下来根据实际环境中的包管理器，执行对应流程：

### yarn（首选）

1. 启用 *yarn* 包管理工具
   ```shell
   corepack enable yarn
   ```
2. 安装 *vsce*
   ```shell
   yarn global add @vscode/vsce
   ```
3. Clone 仓库，在根目录下执行

   ```shell
   yarn install
   ```
4. 使用 VS Code 打开工程，按 **F5** 进行调试
5. 在根目录下执行

   ```shell
   vsce package --yarn
   ```
   完成打包

### npm

1. 安装 *vsce*
   ```shell
   npm install -g @vscode/vsce
   ```
2. Clone 仓库，在根目录下执行

   ```shell
   npm install
   ```
3. 使用 VS Code 打开工程，按 **F5** 进行调试
4. 在根目录下执行

   ```shell
   vsce package
   ```
   完成打包
